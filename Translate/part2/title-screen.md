# Стартовый экран

Давайте реализуем титульный экран! Сначала скопируйте [тайлы и тайлмап](https://github.com/gbdev/gb-asm-tutorial/raw/master/unbricked/title-screen/tilemap-titlescreen.asm) и вставьте в конец вашего кода. Стартовый экран будет выглядить так:

<img
  class="pixelated"
  src="../assets/part2/img/title-screen.png"
  alt="Title Screen"
/>

Затем скопируйте и вставьте следующий код после цикла WaitVBlank:

```rgbasm,linenos,start={{#line_no_of "" ../../unbricked/title-screen/main.asm:title_screen}}
{{#include ../../unbricked/title-screen/main.asm:title_screen}}
```

Обратите внимание, что мы используем реализованную ранее функции [`MemCopy`](./functions.md) для копирования тайлов и [`UpdateKeys`](./input.md), чтобы определить момент, когда нужно запустить игру, посредством создания цикла, который завершаертся при нажатии кнопки Start. 

Все!

## Рефакторинг
Наш проект разрастается, в следствие чего нам нужно провести небольшой _рефакторинг_. До сих пор мы писали весь код в одном-единственном файле `main.asm`, однако, как вы, наверное, заметили, его размеры уже превышают 600 строк! Очевидно, что, если мы продолжим писать по старому, наш проект превратится в нечитаемое месиво. Для решения данной проблемы RGBDS предлагает выносить некоторые участки кода в другие файлы. Это позволит нам сохранять кодовую базу в чистоте (что необходимо при командной работе). В качестве примера можем вынести всю локигу [обработки ввода](./input.asm) в отдельный файл [`input.asm`](https://github.com/gbdev/gb-asm-tutorial/raw/master/unbricked/title-screen/input.asm).

Обратите внимание на использование спаренного двуеточия (`::`) после имен функций и переменных. С его помощью мы говорим RGBASM, что эту функцию/метку/переменную/... можно использовать в других файлах (расширяем [область видимости](https://ru.wikipedia.org/wiki/%D0%9E%D0%B1%D0%BB%D0%B0%D1%81%D1%82%D1%8C_%D0%B2%D0%B8%D0%B4%D0%B8%D0%BC%D0%BE%D1%81%D1%82%D0%B8)). Теперь после рефакторинга нам остается только собрать проект. Каждый файл нужно скомпилировать по отдельности, затем провести линковку:

```console,linenos,start={{#line_no_of "" ../../unbricked/title-screen/build.sh:multibuild}}
{{#include ../../unbricked/title-screen/build.sh:multibuild}}
```

Попробуйте выделить аналогичным образом другие участки кода в отдельные файлы, чтобы уменьшить размер `main.asm` хотя бы до 400 строк. Не забудьте, что каждый файл нужно компилировать _отдельно_, а линковку проводить для _всех разом_!
